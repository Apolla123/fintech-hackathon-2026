# Система заявок для хакатона «Академия Финтеха 2026»

## Как запустить

1. Установи Python 3.8+
2. Установи библиотеки: pip install -r requirements.txt
3. Запусти сервер (написать в терминале): uvicorn main:app --reload
4. Открой в браузере: http://127.0.0.1:8001

## Что делает проект

- Создание заявок
- Назначение ответственного
- Изменение статуса
- Аналитика по заявкам
