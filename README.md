# Система заявок для хакатона «Академия Финтеха 2026»

## Как запустить

1. Установи Python 3.8+
2. Установи библиотеки: `pip install -r requirements.txt`
3. Запусти сервер (написать в терминале): `uvicorn main:app --reload`
4. Открой в браузере: http://127.0.0.1:8000

## Что делает проект

- Вход без пароля: нажимаешь «Зайти», выбираешь роль (гость / сотрудник / руководитель) и пишешь имя
- Создание заявок
- Каждая роль видит своё и может делать своё (см. таблицу ниже)
- Дата выкладки заявки («06 окт. 2026, 22:58 · 23 дн. назад»)
- Сортировка заявок: по умолчанию сначала свободные; можно по назначенным, по дате, по статусу, по ответственному, по названию; плюс фильтр по статусу и поиск
- Архив: когда заявке ставят статус «Выполнена», она переезжает из `data.json` в `archive.json`; руководитель может вернуть её из архива
- Статистика для руководителя: общие цифры и таблица по каждому сотруднику

## Роли

| Что можно | Гость | Сотрудник | Руководитель |
|---|---|---|---|
| Создать заявку | ✅ | ✅ | ✅ |
| Какие заявки видит | только свои (созданные им) | свободные + назначенные на него | все |
| Взять свободную заявку себе | — | ✅ | — |
| Отказаться от заявки | — | ✅ (только от своей) | ✅ (снять с любой) |
| Назначить сотрудника | — | — | ✅ |
| Менять статус | — | ✅ (только у своих) | ✅ |
| Статистика | — | — | ✅ |
| Вернуть заявку из архива | — | — | ✅ |

Права проверяет сервер (`main.py`), а не только страница: даже если сотрудник отправит запрос руками, чужие заявки ему не придут.

## Файлы

- `main.py` — сервер (FastAPI)
- `templates/index.html` — страница сайта
- `data.json` — активные заявки
- `archive.json` — выполненные заявки (архив)
- `users.json` — кто заходил на сайт (создаётся сам при первом входе)
